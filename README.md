TripHive

TripHive is a simple **Tripadvisor-inspired travel website clone** created using **HTML and CSS**.

Technologies Used

* HTML5
* CSS3
* Font Awesome
* Unsplash Images

Features

* Travel-focused homepage
* Navigation bar
* Search section
* Destination and attraction cards
* Responsive layout
* CSS hover effects and transitions
* Clean and modern UI
* Compact footer

Purpose

This project was created to practice **HTML and CSS** and to understand how to build a modern travel website layout from scratch.
